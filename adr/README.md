# Architecture Decision Records

One file per decision that would otherwise be re-argued every few months.

An ADR records why a door was closed, not just which door was taken. The
"Alternatives rejected" section is the part that earns its keep: it is what
stops a future contributor — or a future us — from spending a week rediscovering
that an option does not work.

Numbering is sequential and never reused. A superseded ADR is not deleted: its
status becomes `Superseded by ADR-XXXX`, so the history stays readable.

Use `0000-template.md` as the starting point.
