# Spike reports

One report per milestone, recording what was measured and what it changed.

A report states, for each probe: the question, the protocol actually run
(including any deviation from the plan), the raw measurements, the answer in one
sentence, and the impact on the specification with the affected requirement
references.

Amendments to the specification are dated and carry the reference of the probe
that motivated them. A specification that changes without a trace becomes a
specification nobody trusts.
