# Documents reçus

Tout document reçu qui n'est pas le cahier des charges : maquettes, exports, comptes rendus de
réunion, réponses écrites du métier. Nommés `AAAA-MM-JJ-<origine>-<sujet>.<ext>`, jamais modifiés.
Ce qu'on en tire va dans les registres (`Q-nn` répondue, `E-nn` précisée, `D-nn` tranchée) avec
le renvoi vers le fichier.

Un document confidentiel va dans `confidentiel/` (gitignoré) et son chemin dans `CLAUDE.local.md`.
